# Case study: Tittis Städ

How Webraketen built a fast booking funnel for [Tittis Städ](https://tittisstad.se), a cleaning company in Göteborg. Built and maintained by [Webraketen](https://webraketen.se).

## What Tittis Städ does

Hemstäd, flyttstäd, fönsterputs and kontorsstäd in Göteborg with RUT-avdrag. Insured staff, fixed prices, online booking.

→ [tittisstad.se](https://tittisstad.se)

## Stack

- **Astro** for fast static SEO landing pages
- **Netlify** for hosting and booking-form functions
- **Resend** for transactional email
- **PostHog** for funnel analytics
